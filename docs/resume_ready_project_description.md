# Resume-Ready Project Description

## Short Version

Built an end-to-end Global Sales Performance dashboard using Kaggle Superstore data to analyze sales, profit, customer segments, regional performance, product trends, discount impact, and 3-month sales forecasting. Created SQL queries, DAX KPI measures, Python cleaning/EDA scripts, business insights, and dashboard documentation for executive decision-making.

## Resume Bullet Points

- Developed a business intelligence dashboard for retail sales performance using Superstore order data, Power BI/Tableau, SQL, Python, and DAX.
- Cleaned and transformed raw CSV/Excel data by handling nulls, removing duplicates, standardizing columns, validating data types, and creating calculated fields.
- Built KPI metrics including Total Sales, Total Profit, Profit Margin %, Sales Growth %, Average Order Value, Customer Count, and Quantity Sold.
- Performed SQL analysis for top products, monthly revenue, region-wise profit, customer lifetime value, discount impact, and loss-making products.
- Designed interactive dashboard pages with trend charts, maps, category analysis, customer segmentation, product rankings, slicers, drill-downs, and forecasting.
- Generated actionable recommendations to improve revenue, reduce loss-making products, optimize discounts, and strengthen regional performance.
