# Global Sales Performance & Business Insights Dashboard

An end-to-end Business Analyst portfolio project built around the Kaggle Sample/Global Superstore dataset. The project analyzes retail order data to uncover revenue, profit, customer, regional, product, discount, and growth insights, then converts those findings into a dashboard-ready BI solution.

Dataset source: [Kaggle search - Sample Superstore Dataset](https://www.kaggle.com/search?q=sample+superstore+dataset)

## Project Overview

This project simulates a real business intelligence engagement for a retail superstore. The workflow starts with raw Excel/CSV data, cleans and validates the dataset, performs SQL and Python exploratory analysis, defines dashboard KPIs, and documents executive-level business recommendations.

Primary business questions:

- Which regions, states, categories, and products drive the most sales and profit?
- Where is the business losing money?
- How do discounts affect profitability?
- Which customer segments contribute the most value?
- What sales pattern should leadership expect over the next 3 months?

## Dataset Information

Use a Kaggle Superstore dataset that contains order-level retail transactions. The project supports both common Sample Superstore and Global Superstore variants.

Expected columns include:

- Order ID, Order Date, Ship Date
- Customer ID, Customer Name, Segment
- Region, Country, State, City
- Category, Sub-Category, Product Name
- Sales, Quantity, Discount, Profit, Shipping Cost

If your downloaded file does not include `Shipping Cost`, the cleaning script creates the field with `0.00` so dashboard and SQL logic remain stable.

## KPI Definitions

- Total Sales: Sum of sales revenue.
- Total Profit: Sum of order-line profit.
- Profit Margin %: Total Profit divided by Total Sales.
- Sales Growth %: Period-over-period sales growth.
- Average Order Value: Total Sales divided by distinct orders.
- Customer Count: Distinct customer count.
- Total Quantity Sold: Sum of units sold.

## Steps To Run

1. Download a Sample Superstore or Global Superstore dataset from Kaggle.
2. Place the file in `data/raw/`.
3. Install Python dependencies:

```bash
pip install -r requirements.txt
```

4. Clean the data:

```bash
python scripts/clean_superstore.py --input data/raw/YOUR_FILE.csv --output data/processed/superstore_clean.csv
```

For Excel:

```bash
python scripts/clean_superstore.py --input "data/raw/Sample - Superstore.xls" --output data/processed/superstore_clean.csv
```

5. Run EDA:

```bash
python scripts/eda_superstore.py --input data/processed/superstore_clean.csv --output-dir data/processed
```

6. Generate a 3-month forecast:

```bash
python scripts/forecast_sales.py --input data/processed/superstore_clean.csv --output data/processed/sales_forecast_3_months.csv
```

7. Import `data/processed/superstore_clean.csv` and `data/processed/sales_forecast_3_months.csv` into Power BI or Tableau.
8. Use `dax/powerbi_measures.dax` for Power BI KPI measures.
9. Use `sql/superstore_analysis.sql` for SQL portfolio analysis.

## SQL Explanations

The SQL file includes queries for:

- Top 5 best-selling products
- Monthly revenue analysis
- Region-wise profit analysis
- Highest profit categories
- Customer lifetime value
- Most discounted products
- Sales growth trends
- Loss-making products

The queries assume a cleaned table named `superstore_orders` with snake_case columns, matching the output from the Python cleaning script.

## Business Insights

The final insight report is available in `docs/business_insights_report.md`. It includes a reusable executive summary format plus SQL/Python-driven insight prompts so results can be finalized after the dataset is loaded.

Typical expected findings from Superstore analysis include:

- High sales regions are not always the highest-margin regions.
- Heavy discounting often produces negative profit in specific sub-categories.
- Technology and office supply categories commonly produce strong revenue, but profitability varies by product.
- A small set of customers and products usually account for a disproportionate share of revenue.
