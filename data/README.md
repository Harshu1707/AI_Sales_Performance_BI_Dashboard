# Data Folder

Place the Kaggle dataset file in `data/raw/`.

Supported input formats:

- `.csv`
- `.xls`
- `.xlsx`

Generated outputs are written to `data/processed/`.

Recommended raw filenames:

- `Sample - Superstore.csv`
- `Sample - Superstore.xls`
- `Global Superstore.csv`

The cleaning script standardizes headers to snake_case and creates dashboard-ready calculated columns.
